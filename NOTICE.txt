Project origin

The MCP adapter is based on the MemoryShield+ AML memory service by
GFDDFDGHJ. The bundled backend is method version v3.17.1 from
https://github.com/GFDDFDGHJ/memoryshield-plus-aml
Commit 2d5561a42233d34ba4d535ec24936489bd2e12cc.

This release adds MCP stdio tools, an operator-configured namespace,
sanitized HTTP errors, Add receipt validation, installation examples,
a separate self-hosted database configuration and synthetic integration
tests. Backend retrieval algorithms remain those of the cited source.
backend/PROVENANCE.txt provides file hashes. backend/NOTICE.txt preserves
the upstream historical attribution document, including its earlier
v3.14.0 configuration statements.

Actual model use in this release

Add uses official OpenAI gpt-4o-mini and DashScope text-embedding-v4.
Search uses text-embedding-v4 and optionally qwen3-rerank.
The default Compose deployment disables reranking. The backend returns
stored evidence for the host agent to evaluate. Provider access and usage
charges are the operator's responsibility.
