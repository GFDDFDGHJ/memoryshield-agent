This directory contains a source allowlist copied from the local v3.17.1
backend deployment. The Python files below are byte-for-byte copies. The
MCP adapter is maintained separately in the parent package. No operational
database, request log, credentials or evaluation payload is included.
The original MIT license and attribution remain in LICENSE and NOTICE.txt.

Docker deployment uses a separate named volume and an explicit AML_DB_PATH.
Compose requires API credentials supplied by the operator, enables API
authentication and leaves reranking disabled unless the operator enables it.
The original NOTICE.txt describes the upstream competition history. Its old
version-specific statements are historical provenance.
